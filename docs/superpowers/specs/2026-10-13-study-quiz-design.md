# Study Quiz — design spec (2026-10-13)

## Purpose

A study app for Ben's daughter (year 6, Internationella Engelska skolan Örebro).
A booklet of school material is turned into a question set. The app quizzes her
with instant right/wrong feedback and keeps asking until every question has been
answered correctly. Future booklets will differ in subject and language.

Decisions made by Ben on 2026-10-13:

- No AI calls from the app and no API key in the app. Question sets are
  generated by Claude (in a Claude Code session or a normal Claude chat) and
  either committed to the repo or pasted into the app's Import screen.
- Question format: mix of 4-option multiple choice and short typed answers.
- Questions are in the language of the material (Swedish for the first set).
  The UI has an EN/SV toggle like the sibling apps.
- Deploy to GitHub Pages at https://bengibson1951-bit.github.io/quiz/.

## Shape

Static PWA, no build step, same pattern as hangman / mathsprint / flashcards:
`index.html`, `style.css`, `app.js`, pure modules, `sw.js`, `manifest.json`,
`icons/`, `npm test` via node:test. Folder `Bright Blue Project - Event/quiz`,
own git repo on `main`, repo-local identity. Preview via `quiz` entry (port 4330)
in the parent `.claude/launch.json`.

## Question sets

`sets/index.json`: `[{ "id", "file", "title", "subtitle", "lang", "count" }]`.

`sets/<id>.json`:

```json
{
  "id": "idrott-ak6-anatomi",
  "title": "Anatomi, Fysiologi, Kost och Idrottsskador",
  "subtitle": "År 6 · Idrott och Hälsa",
  "lang": "sv",
  "created": "2026-10-13",
  "questions": [
    { "id": "q01", "type": "mc", "topic": "Anatomi",
      "q": "Hur många ben har skelettet hos en vuxen människa?",
      "options": ["Drygt 206", "Drygt 106", "Drygt 306", "Drygt 406"],
      "answer": 0,
      "explain": "Skelettet består av drygt 206 ben och är levande vävnad." },
    { "id": "q02", "type": "text", "topic": "Behandling",
      "q": "Vad står C för i PRICE?",
      "answers": ["compression", "kompression", "tryck"],
      "explain": "C = Compression (tryck): vira ett elastiskt förband stramt direkt." }
  ]
}
```

Rules: `answer` is the index into `options` as authored; options are shuffled
on every presentation. `answers` lists accepted spellings; the first is the
canonical one shown as the correct answer. `explain` is one sentence taken from
the material. `topic` groups questions on the results screen.

Imported sets (pasted JSON) are stored in localStorage and listed under the
bundled ones. Validation (`sets.js: validateSet`) rejects a set that is missing
required fields, has an `mc` question without exactly 4 options or an invalid
`answer` index, or a `text` question with no answers. `tools/validate-sets.js`
runs the same validation over `sets/*.json` (`npm run validate`).

`docs/QUESTION-SETS.md` documents the format and includes a prompt that produces
a valid set from photos of a booklet.

## Quiz engine (`quiz.js`, pure, tested)

- `createRun(questions, rng)` → `{ queue: [ids shuffled], done: [], attempts: {id: n}, wrong: {id: n}, total }`.
- `current(run)` → the question id at the head of the queue.
- `answer(run, given, rng)`:
  - grades `given` against the question (`grade(question, given)`),
  - increments `attempts[id]`,
  - correct: id moves to `done`,
  - wrong: `wrong[id]++`, id is re-inserted at a random position in the queue
    that is at least 2 places ahead when the queue has 3 or more items left,
    otherwise at the end (so the same question is never asked twice in a row
    unless it is the only one left),
  - returns `{ correct, correctAnswer, explain }`.
- `isFinished(run)` → queue empty.
- `summary(run)` → `{ total, firstTry, attempts, missedIds }` where `firstTry`
  is the number of questions with `wrong[id] === 0`.
- `grade`:
  - `mc`: `given` is the option text; correct if it equals `options[answer]`.
  - `text`: normalise both sides (lowercase, trim, collapse whitespace, strip
    punctuation and hyphens). Correct if normalised `given` equals any
    normalised accepted answer, or if the Levenshtein distance to any accepted
    answer is ≤ 1 for answers of 5–9 characters or ≤ 2 for 10+ characters.
    Empty input is wrong.
- `shuffleOptions(question, rng)` → `{ options: [...shuffled], correct: text }`.

## Persistence (`store.js`, key `quiz.v1`)

```
{ lang: "sv"|"en",
  imported: { [setId]: set },
  history: { [setId]: { last: {date, total, firstTry, attempts}, bestPct: n } },
  resume: { [setId]: { mode, run, shuffled: {id: [optionTexts]} } } }
```

`resume[setId]` is written after every answer and cleared on finish, so a page
refresh or a quit mid-quiz can be continued later from Home. One slot per set,
so starting another set does not lose progress in the first.

## Screens (`app.js`)

- **Home**: brand row with EN/SV toggle and a ⚙ Settings button. Card per set
  (bundled, then imported) with title, subtitle, question count, last result
  ("12/14 first try") and best. Tapping a set starts a full run. A "Continue"
  card appears first for every set with a saved run.
- **Quiz**: Quit chip, progress bar (done / total) and remaining count, topic
  label, question text, then either 4 option buttons or a text input with a
  Check button (Enter submits). After answering: the chosen option turns
  green/red, the correct one is highlighted, a feedback banner shows
  "Rätt!"/"Fel" plus the correct answer and the explanation, and a Next button
  appears. Next advances.
- **Results**: big first-try percentage with a stars rating (3 stars ≥ 90%,
  2 ≥ 70%, 1 otherwise), total attempts, list of missed questions grouped by
  topic with their correct answers and explanations. Buttons: "Again"
  (full set), "Only the ones I missed" (hidden when none), "Home".
- **Settings**: EN/SV, Import set (textarea, Import button, error message on
  invalid JSON), list of imported sets with Delete, "Clear results" link.

Modes: `full` (all questions) and `missed` (ids from the last summary). Both
use the same engine.

## Visual style

Same mobile-first kid style as mathsprint (rounded cards, bold colours, 3D
button shadows), green/red feedback with the shake animation on wrong. Theme
colour mint `#00b894`. Max width 480px, 16px gutters.

## PWA

`manifest.json` ("Study Quiz" / "Pluggquiz"), `sw.js` cache-first with cache
`quiz-v1` listing the shell files and `sets/*`. Bump on every deploy.

## Testing

`tests/quiz.test.js` (node:test, seeded PRNG): shuffle covers all ids;
correct removes from queue; wrong re-queues and never lands at position 0 when
3+ remain; run finishes only when all are correct; summary counts first-try
correctly; grade accepts case/punctuation/one-letter slips and rejects empty or
different answers; mc grading by text. `tests/sets.test.js`: validation accepts
the bundled sets and rejects malformed ones. Manual browser check through the
preview server on phone width.

## Out of scope

AI calls from the app, accounts or sync, timers, sounds, images in questions.
